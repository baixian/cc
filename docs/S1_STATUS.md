# S1 开发记录 · 2026-10-18

## 已有闭环

1. P00 接受用户显式输入的本机控制器地址，仅允许 `http://127.0.0.1:port` 或 `http://[::1]:port`；macOS 上只读观察代理、DNS 和默认路由配置摘要，不返回对应地址。读取失败或无法识别时显示 UNKNOWN。
2. Rust 请求 `/version` 确认控制器响应；拒绝重定向、代理环境变量、非本机 IP、路径、查询参数、凭据和无端口地址。
3. 连接成功后 `/connections` 取真实连接数量及可用的累计字节字段；失败显示 `UNKNOWN` 与具体错误，不把旧会话当作可用。
4. E 模式仅只读。无 Secret 的控制器可以使用；需要 Secret 的控制器返回 `CORE_AUTH_REQUIRED`。尚未实现 Keychain 中的 Secret 原生输入。
5. P00–P10 导航完整；P00/P01/P03/P04/P05/P06 有部分真实 IPC，其他业务内容仍为待接入状态。P01 汇总本机控制器链路证据，P05 支持只读连接筛选与分页；两页都使用定时快照，过期或断线显示未知。P06 仅手动检测本机控制器接口。链路证据不是 macOS 系统路由证明。
6. P03 只读展示 `/proxies` 节点、策略组及 `/providers/proxies` 提供者摘要，提供者读取失败会单独标明。P04 只读展示 `/rules` 有序规则，并按首个命中顺序模拟 ASCII 域名；不确定前置规则返回 `UNSUPPORTED`。这两页没有订阅写入、节点切换或规则应用能力。
7. P09 可读取和保存本机页面刷新间隔（2–30 秒），使用版本号防止并发覆盖，写入应用配置目录。损坏的设置文件不会被静默重置；此设置不涉及网络接管、凭据或更新。
